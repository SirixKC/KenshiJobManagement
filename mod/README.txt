Kenshi Job Management 0.1.0-alpha
=================================

This is a source-first field-test build for RE_Kenshi/KenshiLib.

Open the queue editor:
  Ctrl+J

The window manages the currently selected player character's ordinary Kenshi
permanent-job queue. It can toggle Jobs, move a selected queue row, remove one
row, or clear all rows after a two-click confirmation.

SAFETY
------
This build has not yet been compiled or tested inside Kenshi. Use a disposable
save. Test Remove before testing Move Up/Move Down. Keep a backup from before
installation and inspect RE_Kenshi_log.txt after the first run.

INSTALL
-------
Place this entire folder at:
  <Kenshi>\mods\KenshiJobManagement\

Enable KenshiJobManagement in the launcher and ensure RE_Kenshi is installed.
